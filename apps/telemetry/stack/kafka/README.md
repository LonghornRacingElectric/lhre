# Kafka and bridge

This package owns the Kafka Compose configuration and the Go gRPC-to-Kafka
bridge. Kafka itself is a pinned upstream image; the bridge is built
hermetically with rules_go and its protobuf libraries are generated by Bazel.

```bash
bazel build //apps/telemetry/stack/kafka:kafka_bridge_binary
bazel build //apps/telemetry/stack/kafka:kafka_bridge_image
bazel run //apps/telemetry/stack/kafka:kafka_bridge_load
bazel test //apps/telemetry/stack/kafka:kafka_bridge_smoke_test
```

`go.mod` and `go.sum` remain the dependency source for Go-aware editors and
Gazelle. After a dependency edit, update the Go module checksums and commit the
resulting `MODULE.bazel.lock` change. Protobuf Go packages are build outputs;
they are not checked into `proto/`.

Compose expects both `lhre/telemetry-kafka:4.1.0` and
`lhre/telemetry-kafka-bridge:dev` to be loaded. The root
`//apps/telemetry:load_core_images` target does both.
